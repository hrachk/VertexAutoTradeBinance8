# Аудит и исправления — ветка `release/v6-production` (база: `NEW-PSUPERVISOR` @ 2a393aa)

Объём: ~20 тыс. строк C# (.NET 8), 3 проекта. Сборка решения: 0 ошибок. DI-контейнер проверен
отдельным resolve-харнессом (70 сервисов). Реальная торговля в рамках аудита не запускалась.

## UI (Web) — редизайн

Новая дизайн-система `vertex-ui.css` (графит, кобальтовый акцент, табличные моно-цифры), новый каркас
(сайдбар с SVG-иконками, верхняя панель: equity / unrealized / PnL за день / сессия / **ON/OFF с подтверждением**).

Новые экраны: **Dashboard** (KPI, кривая equity, риск-панель с дневным лимитом, позиции, последние закрытия),
**Positions** (живые позиции с биржи, SL/TP, R-кратность, стадия сопровождения, прогресс SL→TP1 — раньше
страница была заглушкой), **Trade journal** (фильтры, период, статистика: win rate, PF, expectancy).
Settings дополнены параметрами v6. Удалены шаблонные Counter/FetchData/Weather и неработающий
SignalR-клиент (подключался к самому себе; события между процессами не доходили).
